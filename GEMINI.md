# Tutoriais do eproc

Este projeto é um site estático baseado em Jekyll, hospedado no GitHub Pages, que disponibiliza conteúdos diversos.

## Visão Geral do Projeto

- **Tecnologia:** Jekyll (Ruby)
- **Tema:** Slate (`pages-themes/slate@v0.2.0`)
- **Objetivo:** Repositório de materiais que podem ser acessados em qualquer lugar.
- **Estrutura Principal:**
  - `_config.yml`: Configurações do site Jekyll.
  - Todos arquivos markdown devem ficar na raiz.

## Comandos Úteis

### Jekyll (Local)
Para visualizar o site localmente (requer Ruby e Jekyll instalados):
- `bundle exec jekyll serve` (TODO: Verificar se existe um Gemfile para dependências específicas)

## Convenções de Desenvolvimento

- **Markdown:** Utilizar sintaxe Markdown padrão compatível com o tema Slate.

## Uso

Este repositório serve como fonte para o site publicado em `https://jonyduque.github.io`. Alterações feitas na branch `main` são publicadas automaticamente via GitHub Actions ou integração nativa do GitHub Pages.
